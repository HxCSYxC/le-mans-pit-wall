# 24h 維修站指揮官

A Le Mans 24 Hours pit-strategy game in a single HTML file. Pick a 2026 Hypercar team, then manage fuel, tyres, drivers, weather and safety cars over 24 hours. Includes a 3D garage, pit cam, engineer calls and a tyre-change timing mini-game.

Open `index.html` in a browser to play. It needs an internet connection for fonts and three.js.

Unofficial fan-made game, not affiliated with the ACO, FIA WEC or any manufacturer or team. Team names and numbers follow the 2026 entry list, livery colours are approximate, no official logos are used, and the drivers are fictional.
